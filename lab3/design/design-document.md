## Development process

1. Make UI Sketch
2. Write app logic
3. Build Page UI
4. Build Components UI
5. Code the logic

## Requirements

1. Add list items
2. Remove list items
3. Mark items as done
4. "Done" and "To Do" should be listed separately
5. Preserve list after page refresh (cookies or some shit/session management)
6. Notification mechanism. Set time for user to be notified.
7. (feature) Import/Export items
8. (feature) Delete All items and make a pop-up to ask if the user is sure.
9. (feature) Dark Theme
10. (feature) Mobile Support
